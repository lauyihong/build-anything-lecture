# Code / 代码

每周一个文件夹，命名为 `week-NN-<slug>/`，与课件同名，例如 `week-01-intro/`。每个文件夹里放一个 `README.md`，写清楚环境要求和运行方法。

在 `site/src/data/course.ts` 对应那一周里写上 `code: 'week-01-intro'`，网站上就会出现代码链接。
